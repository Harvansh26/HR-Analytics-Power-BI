# HR Analytics Dashboard | Power BI

Project Overview
An interactive HR Analytics Dashboard built using Microsoft Power BI to analyze employee attrition, workforce demographics, salary patterns, and job satisfaction.

Business Problem
HR teams need an effective way to understand employee turnover patterns and identify workforce segments where attrition is concentrated. This project transforms raw HR data into an interactive dashboard that supports workforce analysis and data-driven decision-making.

Objectives
- Analyze employee attrition across departments, age groups, and salary slabs.
- Examine job satisfaction across different job roles.
- Explore the relationship between employee tenure and attrition.
- Track key workforce metrics through interactive visualizations.

Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- CSV data
- Data Visualization and Exploratory Data Analysis

Key Performance Indicators
- Total Employees
- Attrition Rate
- Average Monthly Income

Dashboard Visualizations
- Attrition by Education Field
- Attrition by Age Group
- Attrition by Salary Slab
- Job Role vs. Job Satisfaction Matrix
- Years at Company vs. Attrition Count
- Department-wise Attrition
- Interactive Gender and Department slicers

 Business Value
The dashboard helps HR teams identify attrition hotspots, compare workforce segments, and investigate potential employee retention challenges.

## How to Use
1. Download the `.pbix` Power BI report from this repository.
2. Open it using Microsoft Power BI Desktop.
3. If prompted, update the data source path to the included CSV file.
4. Refresh the data and explore the dashboard using the slicers.

## Disclaimer
This project is intended for educational and analytical purposes. The findings show patterns in the dataset and do not establish causation.
